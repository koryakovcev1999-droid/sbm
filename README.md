# СберМобайл — интерактивный прототип

Статический сайт с личным кабинетом, четырьмя SIM-картами, сториз, тарифным мэтчем, экраном сети и пополнением баланса.

Подготовлен из актуальной сборки от 9 ноября 2026 года. Изображения оптимизированы, шрифты хранятся в репозитории. Установка зависимостей для запуска не требуется.

## Vercel

Импортируйте репозиторий в Vercel. Файл `vercel.json` задаёт Framework Preset **Other**, команду сборки `npm run build` и выходную папку `dist`. После импорта обновления ветки `main` автоматически публикуются на Vercel.

## GitHub Pages (дополнительный вариант)

Для GitHub Pages используйте ветку `main`, папку `/ (root)`. После включения Pages адрес сайта:

https://koryakovcev1999-droid.github.io/sbm/

Если публикация ещё не включена: откройте **Settings → Pages**, выберите **Deploy from a branch**, затем **main** и **/ (root)**, нажмите **Save**. Последующие изменения в `main` публикуются автоматически.

## Локальный запуск

Нужен Node.js 20 или новее:

```sh
npm run dev
```

Откройте http://127.0.0.1:4173. Для другого порта используйте переменную окружения `SBM_PREVIEW_PORT`.

## Сборка для другого хостинга

```sh
npm run build
```

Готовые файлы появятся в `dist/`. Загрузите содержимое этой папки в корень сайта. `index.html` должен находиться прямо в корне.

## Страницы

| Адрес | Экран |
| --- | --- |
| `index.html` | Главная, первая SIM |
| `index.html?sim=second` | Вторая SIM |
| `index.html?sim=third` | Третья SIM и тарифный мэтч |
| `index.html?sim=fourth` | Четвёртая SIM и компактные сториз |
| `profile.html` | Профиль |
| `assistant.html` | Ассистент |
| `network.html` | Сеть |
| `match.html` | Подбор тарифа |
| `topup.html?sim=3` | Пополнение четвёртой SIM |

## Обновления

- Разметка страниц — `*.html`, стили — `*.css`, поведение — `*.js`.
- Контент сториз — `stories-content.json`.
- Иллюстрации и иконки — `assets/`, шрифты — `fonts/`.
- После изменения CSS или JavaScript обновите параметр `?v=` у соответствующего подключения в HTML, чтобы браузеры загрузили новую версию.

Это демонстрационный интерфейс: серверная авторизация, реальные платежи и управление услугами не подключены. Кнопки без реализованных переходов сохраняют поведение исходного прототипа.
